## Project Overview

This is an Android application built with Kotlin and Jetpack Compose. It is a single-module project (`:app`) using the standard Android Gradle Plugin and Kotlin Compose compiler.

- **Package:** `com.example.chaserpa`
- **Compile SDK:** 36 (with minor API level 1)
- **Min SDK:** 24
- **Target SDK:** 36
- **Java compatibility:** 11
- **Kotlin:** 2.2.10
- **AGP:** 9.2.1
- **UI Framework:** Jetpack Compose (Material3)

## Build & Development Commands

All commands use the Gradle wrapper (`./gradlew`) from the project root.

- **Build the app:** `./gradlew :app:assembleDebug`
- **Install debug APK on connected device:** `./gradlew :app:installDebug`
- **Run local unit tests:** `./gradlew :app:testDebugUnitTest`
- **Run a single unit test class:** `./gradlew :app:testDebugUnitTest --tests "com.example.chaserpa.ExampleUnitTest"`
- **Run instrumented tests:** `./gradlew :app:connectedDebugAndroidTest`
- **Clean build:** `./gradlew clean`

## Architecture

The project follows the standard Android single-module structure generated by Android Studio.

- **`app/src/main/java/com/example/chaserpa/`** — Application source code.
  - `MainActivity.kt` — Single `ComponentActivity` hosting the Compose UI tree via `setContent`.
  - `ui/theme/` — Compose theme definitions (`ChaserpaTheme`, `Color.kt`, `Type.kt`). The theme supports dynamic color on Android 12+ and toggles between light/dark schemes.
- **`app/src/main/res/`** — Android resources (launcher icons, strings, themes, backup rules).
- **`app/src/test/`** — Local JVM unit tests (JUnit 4).
- **`app/src/androidTest/`** — Instrumented tests running on an Android device.

### Theme System

`ChaserpaTheme` is the root theme composable. It uses `MaterialTheme` with:
- Dynamic color schemes when `dynamicColor = true` and the device runs Android 12+.
- Fallback static light/dark color schemes (`LightColorScheme` / `DarkColorScheme`) defined in `Theme.kt`.
- Custom typography from `Type.kt`.

## Notes

- Edge-to-edge display is enabled in `MainActivity` via `enableEdgeToEdge()`.
- `RepositoriesMode.FAIL_ON_PROJECT_REPOS` is set in `settings.gradle.kts`; do not add repository declarations inside `build.gradle.kts` files.
- `local.properties` contains the local Android SDK path and should not be committed to version control.
